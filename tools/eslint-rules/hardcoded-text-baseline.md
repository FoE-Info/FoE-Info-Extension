# Known untranslated text — `no-hardcoded-text` baseline

Each entry is `"<path> :: <text>"`. `tools/eslint-rules/no-hardcoded-text.js`
suppresses exactly these, so the rule fails only on **new** unbound text.
Delete an entry once the text is bound; a stale entry hides a regression.

**Measured 2026-09-27:** 46 findings before this pass, 10 after. The 36 that
were fixed are listed in `docs/TODO.md` §7.

| Entry                                                                                                                         | Why it is not translated                                                                                                                                                                                                                                                                                                                 |
| :---------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `bonusPanel.js :: First Strike`, `Kraken Spoils`, `Himeji Castle Dip lomatic Gifts`, `Space Carrier Aid Goods`, `Truce Tower` | Each entry is split across an `<em>` tag (`First <em>Strike</em> - Kraken`). `translateContainer` assigns `textContent`, so no single element can hold the phrase and a bound value would print the tags literally. The sibling `Legend` heading on the same line _is_ bound. This is the same reasoning recorded in `docs/TODO.md` §11. |
| `incidentsPanel.js :: Event Capitals`, `Rare Reward`                                                                          | The incident legend is one `<p>` split by `<br>` (`w/W - Water<br>r/R - Road<br> E - Event<br>Capitals = Uncommon/Rare Reward`). The `Legend:` heading is bound; the rows are not, for the same `textContent` reason.                                                                                                                    |
| `liveCityViewDataBuilder.js :: FoE`                                                                                           | The product's own name. `Playing <span>FoE</span> since` around it is bound via `playing` / `since`.                                                                                                                                                                                                                                     |
| `ownCityCard.js :: Arc`, `visitedCityCard.js :: Arc`                                                                          | `Arc` is the InnoGames feature name (`Arc Bonus`), not a translated noun. The adjacent `Bonus` is bound via the existing `bonus` key.                                                                                                                                                                                                    |

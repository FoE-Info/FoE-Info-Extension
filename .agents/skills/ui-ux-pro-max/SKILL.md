# UI/UX Pro Max

Design and review user interfaces with explicit accessibility, interaction, responsive, performance, and visual-system constraints.

## When to Use

- Creating or revising a user-facing interface.
- Auditing usability, accessibility, layout, or interaction quality.

## Procedure

1. Establish platform, users, task, viewport range, and existing design system.
2. Select only the relevant design, accessibility, and interaction references.
3. Define states for loading, empty, error, success, focus, hover, and reduced motion.
4. Implement semantic structure and keyboard behavior before visual polish.
5. Check contrast, target sizes, responsiveness, overflow, and content hierarchy.
6. Verify in the real surface at representative viewport sizes.
7. Read [Reference catalog](references/README.md) and load `references/detailed-guide.md` for search workflows, output formats, and the full design-rule set.

## Verification

Provide screenshots or live-surface evidence, accessibility checks, viewport coverage, and unresolved trade-offs.

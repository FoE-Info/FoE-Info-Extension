# Build & Verification Workflow

Standard workflow for linting, testing, and building the extension bundles.

## Steps

1. **Syntax & Lint Check**:
   ```bash
   npm run check
   ```

2. **Incremental Development Build**:
   ```bash
   npm run build:dev
   ```

3. **Production Webstore Build**:
   ```bash
   npm run build
   ```

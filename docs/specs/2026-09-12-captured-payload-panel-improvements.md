# Captured Payload → Panel Architecture Improvements

**Date**: 2026-09-12  
**Evidence**: 43 recorded network captures (8,306 entries / 9,339 RPC responses / 103 unique RPCs), extracted by `scripts/ingest-hars-to-metadata.mjs` into `../metadata-store/extracts/` and indexed into the metadata knowledge graph.

The captures are the exact JSON-RPC responses the extension receives at runtime. They are modeled in the graph as first-class network payloads:

| Node type            | Count | Meaning                                                      |
| :------------------- | ----: | :----------------------------------------------------------- |
| `NetworkRPCPayload`  |   103 | Representative `<Class>.<Method>` response (`rpc-capture:*`) |
| `PayloadBundle`      |    27 | Domain capture sequences (`payload-bundle:*`)                |
| `PlayerCitySnapshot` |    13 | Visited player cities (`player-city:*`)                      |

The metadata graph was rebuilt (5,499 nodes / 46,623 edges) and DeepSeek-relabeled (385 communities).

## 1. Graph Explorer Findings

Questions asked of the metadata graph explorer and what it returned:

- **"How do Great Buildings payloads link to entity definitions?"**
  - `rpc-capture:GreatBuildingsService.getConstructionRanking` → `Château Frontenac` via `building_id`.
  - `rpc-capture:BlueprintService.newReward` → `Cathedral of Aachen` via `cityentity_id`.
  - `payload-bundle:greatbuildings/construction_ranking` → `Saturn VI Gate HYDRA`.
  - The rank-reward rows carry `strategy_point_amount`, `blueprints`, and `resources.medals` — the authoritative reward the server grants.
- **"What does a Quantum Settlement capture connect to?"**
  - `rpc-capture:GuildRaidsOutpostService.getOutpost` → `guild_raids` grid, all settlement buildings (Bakery, Tannery, Copper Foundry, barracks, …), and quantum resources (`Quantum Coins`, `Quantum Supplies`, `Quantum Residents`, `Quantum Brick/Copper/Gunpowder/Honey/Rope`, `Chrono Alloy`).
- **"What do visited cities expose?"**
  - `player-city:phil-knows-best` has 192 building neighbors plus special systems: `Castle System`, `Quantum Incursion`, `Historical Allies`, `Heroic Taverne`, `Antiques Dealer`, `Guild Battlegrounds`, `Guild Expeditions`, `Forge Plus`.
- **"What does the treasury donation history reference?"**
  - `rpc-capture:ClanService.getTreasuryLogs` → space-age guild goods (`Silver Crystals`, `Glyph Circuits`, `Metamorphic Alloys`, `Psionic Conduits`, `Resonance Cores`, `Xenocrystals`).
- **"Which GBG buildings are in play?"**
  - `rpc-capture:GuildBattlegroundBuildingService.getBuildings` → `Watchtower`, `Traps`, `Decoys`, field camps/outposts, guild barracks — matching the attrition-reduction keys in `GbgCalculator`.

## 2. Graph Quality Improvements (already applied)

- Indexed extracts as `NetworkRPCPayload` / `PayloadBundle` / `PlayerCitySnapshot` (no "HAR" terminology — they are network responses).
- Relationship scanner now resolves **string arrays** (`goodsResourceIds`, visited-city `entityIds`), unlocking +7,406 edges.
- Excluded serializer/enum plumbing (`__class__`, `__enum__`, `value`) from relationship detection, removing **3,106 false-positive edges** (e.g. `value:"copper"` → `Copper League`).
- Player-city nodes now carry `entityIds` so a visit is queryable against the building universe.

## 4. Prioritized Roadmap

1. **P0 — GB reward authority**: parse `getConstructionRanking` + `BlueprintService.newReward` into the GB panels; add a level-closing profitability view and a host-levels-self warning. Highest user value and directly exercises the newest captures.
2. **P1 — GB list + FP packages**: `getOtherPlayerOverview` GB list card; `getAvailablePackageForgePoints` in the donation footer.
3. **P1 — Treasury analytics**: per-player donation leaderboard + resource filters on the fixed pagination.
4. **P1 — GBG build efficiency**: `availableBuildings[].costs` ranking + `readyAt` countdowns.
5. **P2 — QI suite**: execute the QI architecture slices.
6. **P2 — Visited-city parity**: expose special-system presence and per-player GB lists.
7. **P2 — Graph gaps**: capture GE 1–5 and record it to close the only major panel without ground truth.

**Invariants**: dynamic runtime metadata only (no baked JSON), BigNumber for all FP/medal/blueprint aggregation, ≤600-line modules, scoped loggers, i18n for every new label.
